Notifikasi otomatis

Tes memakai penyedia dan token yang sudah disimpan. Pada Fonnte, respons berhasil berarti pesan masuk antrean Fonnte.

Fonnte mengirim melalui https://api.fonnte.com/send. Simpan token API dari dashboard Fonnte, aktifkan perangkat WhatsApp di akun, lalu gunakan tes. Pastikan pesan benar-benar diterima di WhatsApp tujuan.

Nomor tujuan dipilih berurutan: WhatsApp calon siswa, lalu ayah, lalu ibu bila nomor sebelumnya kosong. Webhook tidak menerima notifikasi bila tidak ada nomor tujuan.

Untuk webhook kustom, payload berisi event, to, message, dan data; token dikirim sebagai Bearer. Kegagalan pengiriman dicatat pada log server.
